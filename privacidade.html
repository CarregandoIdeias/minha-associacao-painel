Política de Privacidade

Última atualização: 30 de julho de 2026

Aviso importante: este documento é um rascunho estruturado para cobrir os pontos que a LGPD (Lei Geral de Proteção de Dados) exige que uma política de privacidade explique. Os campos marcados como [A PREENCHER] precisam ser completados com os dados reais da empresa antes da publicação, e o texto como um todo deve ser revisado por um profissional jurídico antes de valer como documento definitivo.

1. Quem somos

Esta Política de Privacidade descreve como o ASSOCIA PLUS, operado por [RAZÃO SOCIAL], inscrita no CNPJ [CNPJ] ("nós", "nossa plataforma"), coleta, usa, armazena e protege dados pessoais de quem utiliza o sistema — associações-clientes, seus administradores/diretoria e os associados de cada uma.

Para dúvidas, solicitações ou exercício de direitos sobre dados pessoais, entre em contato pelo e-mail [E-MAIL DE PRIVACIDADE].

2. Quem esta política protege

Esta plataforma é usada por três perfis diferentes, cada um com um tipo de relação diferente com os dados:

  • Associações-clientes (controladoras dos dados dos próprios associados) — contratam a plataforma para gerir seus associados.
  • Administradores/diretoria/equipe de cada associação — pessoas que acessam o sistema em nome da associação.
  • Associados — membros de cada associação-cliente, cujos dados são cadastrados pela própria associação (não se cadastram diretamente na plataforma).

Nesse modelo, cada associação-cliente é a controladora dos dados dos próprios associados perante a LGPD, e o ASSOCIA PLUS atua como operador — processamos os dados seguindo as instruções da associação, através do sistema.

4. Para que usamos esses dados

  • Permitir o cadastro e a gestão de associados pela associação-cliente
  • Gerar e controlar cobranças/mensalidades (Pix) e o histórico financeiro
  • Autenticar o acesso de cada usuário e manter sua sessão
  • Enviar comunicados da associação (e, eventualmente, da própria plataforma) aos associados
  • Gerar carteirinha digital de identificação do associado
  • Manter um log de auditoria das ações administrativas, para segurança e rastreabilidade
  • Emitir cobrança pela assinatura da plataforma à associação-cliente

5. Base legal (LGPD, art. 7º)

O tratamento desses dados se apoia principalmente em:

  • Execução de contrato — os dados de administradores/diretoria e os dados financeiros existem porque são necessários pra prestar o serviço contratado pela associação.
  • Cumprimento de obrigação legal ou regulatória da associação — muitas associações têm obrigação estatutária/legal de manter cadastro de seus membros.
  • Legítimo interesse — para o log de auditoria e para medidas de segurança (ex.: registro de IP em tentativas de login), sempre limitado ao necessário e sem impacto desproporcional aos direitos do titular.

6. Com quem os dados são compartilhados

Não vendemos nem alugamos dados pessoais a terceiros. Os dados são processados pelos seguintes prestadores de infraestrutura, na função de operadores/suboperadores, só na medida necessária para hospedar e operar a plataforma:

  • Supabase — hospedagem do banco de dados (PostgreSQL)
  • Render — hospedagem do servidor da aplicação (backend)
  • Vercel — hospedagem das páginas do painel/portal (frontend)

Dados de um associado só ficam visíveis para a própria associação a que ele pertence — o isolamento entre associações é garantido tecnicamente no banco de dados (Row Level Security), não só por regra de código.

7. Por quanto tempo guardamos os dados

Os dados ficam armazenados enquanto a conta/associação estiver ativa na plataforma. Após o encerramento do contrato com uma associação-cliente, os dados são mantidos por até [PRAZO A DEFINIR] para cumprir eventuais obrigações legais, contábeis ou de defesa em processos, e então eliminados ou anonimizados.

8. Como protegemos os dados

  • Isolamento de dados entre associações reforçado no próprio banco de dados (Row Level Security), não só por lógica de aplicação
  • Senhas armazenadas com hash irreversível (nunca em texto puro)
  • Conexão criptografada (TLS) entre o navegador, o servidor e o banco de dados
  • Acesso da equipe da plataforma aos dados de associações-clientes restrito a suporte técnico, com log de auditoria de qualquer ação administrativa

9. Seus direitos como titular de dados

Nos termos da LGPD, você pode solicitar, a qualquer momento:

  • Confirmação de que tratamos seus dados, e acesso a eles
  • Correção de dados incompletos, inexatos ou desatualizados
  • Anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desconformidade com a lei
  • Portabilidade dos dados a outro fornecedor
  • Eliminação dos dados tratados com base no seu consentimento
  • Informação sobre com quem compartilhamos seus dados

Se você é associado de uma associação-cliente, o pedido normalmente deve ser feito primeiro à própria associação (controladora dos seus dados) — mas também pode nos contatar diretamente em [E-MAIL DE PRIVACIDADE] que encaminhamos ou respondemos dentro do prazo legal.

10. Cookies e armazenamento local

A plataforma não usa cookies de rastreamento nem de terceiros para publicidade. A sessão de login é mantida via localStorage do navegador (um mecanismo técnico, não um cookie), usado só para manter você autenticado.

11. Alterações desta política

Podemos atualizar esta política eventualmente. Mudanças relevantes serão comunicadas com destaque nesta página, com a data da última atualização sempre visível no topo.
